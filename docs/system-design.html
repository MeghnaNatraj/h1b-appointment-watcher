H1B Slot Watcher

A cloud watcher reads the Regular_H1B_H4_VisaSlotsChecking Telegram group around the clock, filters out noise, and rings the Visa Alarm app on your Android phone within seconds of a real slot post.

Visa Alarm app (ntfy) healthchecks.io monitor

Architecture

Three running parts: the watcher on a free Oracle Cloud server, the ntfy.sh push channel in the middle, and the Visa Alarm app on the phone. healthchecks.io sits beside them and rings the same channel if the watcher goes quiet.

Life of one alert

The phone rings before the screenshot is even downloaded. Reading the image happens afterwards and arrives as a second, quieter message.

  1. Someone posts in the group

    Telethon delivers the new message to the watcher's handler. With catch_up=True, messages posted while it was disconnected are delivered after it reconnects, late rather than never.

  2. Filter

    Skips the group's repeating "H1 H4 inperson slots availa..." notice, any text with "NA" or "N/A" as a whole word (CHENNAI still passes), and posts from anonymous admins or the group itself. Any remaining photo or text is an alert.

  3. First push to ntfy

    The message text, or "New slot photo posted" for a bare screenshot, goes to https://ntfy.sh/<NTFY_TOPIC> with title VISA SLOT and priority urgent.

    about 1 s after the post

  4. Phone rings

    The app's open stream receives the event, checks it has not rung for this message id, then plays the alarm sound on the alarm audio stream at full volume with vibration and a full-screen red screen. It rings even on silent or vibrate, for at most 10 minutes, until you tap Dismiss or Open Telegram.

  5. Read the screenshot

    The watcher downloads the image and runs tesseract on it. It picks out the location and dates, for example Hyderabad, 3 dates: Nov 4, 5, 12 2026. It never guesses: no match means no summary.

    a few seconds, capped at 15 s

  6. Second push: Slot details

    If a summary was found, it goes to the same topic with title "Slot details" and priority high. The app shows it on the alarm screen, so a second dismiss may be needed.

  7. Log

    Alert sent: ... is written to the systemd journal on the server.

Components

Watcher

telegram-watcher/h1b_slot_watcher.py
  • Python 3.12, Telethon, runs as Linux user watcher from /opt/h1b-watcher
  • systemd restarts it 30 s after any crash, and on reboot
  • One background task: the healthcheck pinger, every 5 min while connected
  • --test-alert rings the phone with a TEST message without touching the Telegram login

Screenshot reader

telegram-watcher/slot_image.py
  • Local tesseract, no paid service and no account
  • Knows Hyderabad, Chennai, Mumbai, New Delhi, Kolkata and common consulates abroad
  • Off with OCR_ENABLED=false; any failure falls back to the plain alert

ntfy.sh topic

NTFY_TOPIC in .env, baked into the APK
  • Free public push service; the long random topic name works as the password
  • Keeps recent messages, so the app can ask for anything since its last event
  • Also receives watcher problem reports and healthchecks.io "Watcher stopped" posts

Visa Alarm app

android-app/ · package com.meghna.visaalarm
  • ListenerService: foreground service holding one HTTP stream to the topic, with a partial wake lock
  • Reconnects with backoff from 2 s to 60 s and asks for ?since= the last event time
  • Alarm and AlarmActivity: alarm-stream sound, vibration, full-screen intent over the lock screen
  • BootReceiver restarts listening after a phone reboot

healthchecks.io

HEALTHCHECK_URL in .env
  • Dead man's switch: the watcher pings every 5 min while Telegram is connected
  • Missed pings trigger a webhook to the ntfy topic: "Watcher stopped", urgent
  • Recovery posts a quiet "Watcher back"

Server and deploy scripts

telegram-watcher/cloud/
  • deploy.sh copies code, requirements and .env, then runs setup_server.sh
  • setup_server.sh adds 2 GB swap, builds the venv with uv, writes the systemd unit
  • auto_setup.sh requests a new free VM, retrying every 3 min when Oracle is out of capacity

Design choices

Alarm first, details later

OCR can take seconds, so the first push never waits for it. Speed matters more than a tidy single message because slots go within minutes.

A custom app instead of a chat app

Telegram and WhatsApp stay quiet on vibrate and when the chat is open. The app plays on the alarm stream, which Android lets ring through silent mode.

One login, one copy

Two clients on the same Telegram session can get it cancelled, so only the server runs. deploy.sh disables any Mac copy before moving the session.

Read only, zero cost

The watcher never posts in the group. Oracle Always Free, ntfy.sh, healthchecks.io and tesseract all cost nothing, and the Oracle account was never upgraded, so it cannot be charged.
